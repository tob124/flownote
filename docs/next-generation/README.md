# FlowNote 3.0 升级规划 · R2

修订日期：2026-09-22。工程基线：v2.9.0，Git提交c54d9f2。本次只调研、写文档；后续代码施工模型为GPT-5.6-Sol，软件运行时仍使用DeepSeek/PaddleOCR。

## 这次升级的幅度

完整目标是“采集 → 主题知识库 → 有来源的问答/关联/反思 → 可编辑且有版本的成果”。第一版规划中的采集和检索保留为Alpha；主题、洞察、Dream增强、成果工作台、文档解析、笔记管理与Markdown编辑已提升为本次Windows正式版必做，不能做完Alpha就宣称3.0完成。

## 用户已确认的边界

- 个人自用、Windows优先，保留React/Electron/TypeScript及现有数据文件。
- 坚果云继续承担同步/托管/中转，不建设账号后台或自有云服务器。
- 保留并增强“自动分类→Wiki→Dream”，不以主题知识库替换旧流程。
- 不新增语音识别、录音转写、声纹、手机内录和音视频理解。
- 图片使用PaddleOCR提取文字，DeepSeek按需理解/问答；控制成本，不全库重复处理。
- 移动端只做可选文字/图片/链接采集；太难则停留在Windows，不阻塞正式版。
- 对标Get的知识利用流程为主线；旧TODO仅做支撑性增强，不追求清空待办。
- 本轮仅文档，不修改业务代码、真实笔记或API凭据，不调用付费API。
