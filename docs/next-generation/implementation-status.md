## 下一阶段仍需施工

R2 原候选完整规格里的 T03 模型任务/预算队列、T04 来源模型、T05 图片/OCR、T06 网页抓取与快照、T07 大库检索评测、T08 统一引用查看、T09 有证据问答、T15 PDF/DOCX、T17 追问、T18 洞察、T19 Dream 结构化覆盖，以及成果 AI 提纲/草稿等均**未完成**。按 07–10 的 R3 决策，这些能力需以目标回看和用户真实使用价值排序，不引入仅供语义检索使用的 embedding/向量包。网页解读和书籍推荐尤其不能以简陋抓取或凭空推荐冒充可靠体验。

运行中的 `npm run dev` 可先手动验收：记录一条笔记 → 建立目标和主题 → 将笔记加入主题并关联目标 → 写下一项决定与一次回看 → 在成果工作台选目标、资料，写正文并保存 V1 → 修改后保存 V2 → 导出 Markdown；再验证笔记编辑草稿冲突、移入回收站/恢复。开发服务器对主进程或 preload 的修改可能需要重启 Electron；若新入口报告 IPC handler 缺失，先停止并重启 `npm run dev`。

尚未运行 Windows 安装包、真实坚果云文件锁/双设备冲突演练、真实模型或 OCR 调用。当前包是可测试的目标闭环实现，不能标记为 05/06 所述全部 3.0 功能完成。
